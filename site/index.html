vab RPM repository

Fedora packages for a few command-line tools, rebuilt nightly from their GitHub releases.

Install

sudo dnf install calepin
sudo dnf install scrutin
sudo dnf install pulpit
sudo dnf install dadrock
sudo dnf install dadrock-desktop

After that, sudo dnf upgrade picks up new versions.

Notes

The packages here are the same binaries published on each project's GitHub releases page. This repository does not build them; it fetches, indexes and signs them, which is what lets dnf upgrade notice a new version instead of you checking a releases page by hand.

Only stable releases are served. Prereleases stay on GitHub.

RHEL, Rocky and AlmaLinux 9: the repository works there, but calepin, pulpit, dadrock and dadrock-desktop currently need a newer glibc than EL9 ships (2.35 vs 2.34), so they install and then fail at startup. scrutin works.

Debian and Ubuntu users: see the apt repository.
